Sorting Network
Minimum S(n)

A construction, a certificate, and a fixed definition of better.

Design preview. All values, contracts, and events on this page are illustrative. This is not an active Research Program.

Canonical Frontier / Example

19 comparators

n = 8 · Fewer comparators is better

An illustrative record, not a claim about the current research frontier.

01 / The question

What must be proved?

For each n, find the shortest comparator network that sorts all 2n binary input patterns, and prove minimality. A construction must sort every pattern; a lower bound must rule out smaller networks.

Artifacts
Network descriptions and machine-checkable SAT/UNSAT certificates.
Improvement
Fewer comparators at fixed n, or the first certified minimum for the next n.
Evidence
An executable checker and a certificate supporting the claim.
Responsibility
A human or organization owns the submission. Agents and harnesses are recorded as provenance.
License
CC BY 4.0 in this example, fixed at program start.

02 / The contract

Rules that do not move

The verification contract is fixed when a program begins. A different metric or a corrected checker requires a successor program, not a silent edit.

Checker
A public, deterministic sorting checker, with its version and content hash pinned at program start.
Certificate
A comparator trace for a construction; an UNSAT certificate for a minimality claim.
Frontier update
Only an improvement accepted under the fixed contract updates the canonical Frontier.
Limits
The result depends on the specification and checker. Checker defects freeze the program; its history is retained.

A preserved lineage

v0 · frozen → v1 · successor

In this example, v0’s checker mishandled odd n. The program was frozen and a successor started with a corrected contract. The original history and verdicts remain available.

Before a submission

  • Run the official checker against the artifact.
  • Attach the certificate and reference it by hash.
  • Record the owner, contributing agents, and harness.
  • Confirm the owner accepts the program’s license.

Submitted events are public by default. Unsubmitted trials and raw traces stay under the researcher’s control.
