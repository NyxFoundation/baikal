# Baikal サイト デザインテンプレート

構想段階の Baikal を紹介する静的サイト。ビルド工程や実行時のライブラリ依存はなく、HTTP サーバーでそのまま表示できる。Google Fonts の取得に失敗しても本文と操作は利用できる。

## プレビューと検証

リポジトリのルートで実行する。

```sh
python3 -m http.server --bind 127.0.0.1 --directory design 8000
# http://127.0.0.1:8000/index.html
# http://127.0.0.1:8000/program.html
```

別のターミナルで静的な契約を確認する。

```sh
python3 -m unittest discover -s tests
node --check design/landing.js
```

テストは HTML の言語・ランドマーク、リンクとローカルファイルの存在、研究詳細からのアンカー、CSS の分離、構想段階の明記を検査する。画面の読みやすさや操作の完了を保証するものではない。下記のブラウザ確認も行う。

## トップの視覚設計

[Plastic Human](https://plastichuman.org/) の白と鮮烈な青、大きな文字、点群、番号付きの章から着想を得た。人体モデル、画像、音声、実装コードは使用していない。

研究の進展に関心を持つ読者に向けた、研究特集のような紹介ページ。ENERGY / RHYTHM / MOTION は **3 / 3 / 2**。詳細ページの作業的な読み方とは分ける。

| 判断 | 仕様と理由 |
| --- | --- |
| 配色 | `#fafaf8` の紙面と `#1531f5` の青。参考サイトの研究展示らしい鮮明さを取り入れ、本文は `#172443`、補足は `#555e73` で読む密度を下げる |
| 固定ライトテーマ | 白地に青い点群を印刷した研究図版として見せるため。青い検証章はページ内の反転であり、OS のダークテーマではない |
| 欧文 | Schibsted Grotesk。幅のある低重心の字形で、冒頭と末尾に誌面の見出しとしての強さを持たせる |
| 日本語 | Noto Sans JP。説明文の可読性を保ち、見出しも同じ字形でつなぐ |
| 注釈 | IBM Plex Mono。図番号、章番号、参照先を本文から区別する。本文全体や大見出しには使わない |
| 構図 | 冒頭は大見出しと立体図、研究例は開閉できる誌面、検証章は反転した手順図、参加はリンクの一覧。内容ごとに読み方を変える |
| 余白 | 左右は `clamp(1.25rem, 4vw, 4.5rem)`。章の上下は小画面 4rem、中画面 5rem、大画面 7rem。研究の説明はこれより密に組む |
| 点群 | 結び目状の構造と散らばった点で、探索と検証の連なりを表す概念図。証明済み領域の割合や実際の研究データを表さない |
| 図解 | ソートネットワークは問いそのものを説明する。装飾的なカードや実在しない指標は置かない |
| 矢印と開閉記号 | 矢印はページ内の上下移動と別ページへの遷移、プラス・マイナスは開閉の状態を示す |
| 動き | スクロールに応じて点群の見る角度が変わる。自動回転、音声、スクロールの乗っ取り、本文を隠す出現アニメーションは使わない |

### 表示と操作

- 40rem 未満では冒頭を一列に組み、本文、大見出し、図の順に読む。ヘッダーは固定せず、文字拡大で折り返しても本文を覆わない。40rem 以上では図と文章を並べ、ヘッダーを追従させる。68rem 以上で広い誌面にする。
- 点群は Canvas 2D。解像度倍率を 2 までに制限し、描画はスクロール・リサイズ等の通知を `requestAnimationFrame` でまとめる。画面外・非表示の間は新しい描画を予約しない。
- 「動きを止める」は押下状態のあるトグル。停止中にもう一度押すと再開する。`prefers-reduced-motion: reduce` では静止し、トグルを操作不能にする。端末設定を実行中に変えた場合も反映する。
- JavaScript 無効時や Canvas のコンテキスト取得不可時は、HTML 内の静止した概念図を表示する。本文、リンク、ネイティブの `details` による目次と研究例は利用できる。
- 目次は Escape で閉じ、フォーカスを開閉ボタンへ戻す。リンク選択時は対象章へフォーカスを移す。JavaScript 無効時は目次の開閉ボタンで閉じる。
- 研究詳細から参照される `#programs`、`#loop`、`#roles`、`#frontier` を、それぞれ対応する内容の識別子として保持する。
- データ取得、認証、提出フォームは設けていない。架空の稼働状態、更新履歴、CLI のインストールコマンドは表示しない。

## 内容の境界

- 研究例は想定ユースケースであり、稼働中の研究プログラムではない。構想段階であることを研究例の直前とフッターに記す。
- 社会的な期待、形式仕様の下で確かめること、実用化までの条件を分けて書く。測定根拠のない達成率、達成年、最新記録は載せない。
- 検証済みの改善だけが、各 Research Program の単一の公式 Frontier を更新する。失敗・反証・再現失敗は共有知として残す。
- 開始後の検証契約は不変。欠陥があれば凍結し、後継プログラムに移る。過去の成果は削除しない。
- AI は来歴であり、責任主体は人間・組織。形式証明、シミュレーション、現実世界での実証を混同しない。
- 参加導線は GitHub の README、Issues、コミット履歴。開発リポジトリはベータ版として非公開であり、アクセス権が必要なことを操作前に表示する。未ログインでの 404 は公開リンクの成功とは扱わず、認証済み API で存在を確認する。詳細ページへのリンクはサンプルであることを表示する。

## ブラウザでの確認

- 320 / 390 / 720 / 1080 / 1440px、および文字拡大 200% で、横スクロール・文字の欠け・重なりがないか確認する。
- 目次の開閉・Escape・章への移動、各研究例の開閉、動きの停止と再開、本文スキップと先頭への移動をクリックとキーボードで確認する。
- 通常、動きの低減、JavaScript 無効、フォント取得失敗の各条件で本文と操作を確認する。
- ページ内アンカー、詳細サンプル、外部リンクの行き先を一つずつ確認する。コンソールエラーとアクセシビリティ検査も確認する。
- 青と紙面、本文と紙面、補足と紙面、図の背景、白文字と青、操作の hover / active / focus / disabled の組み合わせを測定する。

## 公開

Cloudflare Workers の公開先は **https://baikal.shoukitsuda.workers.dev**。ルートの `wrangler.jsonc` が `design/` を配信する。既存の CI が `master` への変更をデプロイする。ローカルの表示検証は公開環境を更新しない。
