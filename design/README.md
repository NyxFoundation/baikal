# Baikal サイト デザインテンプレート

構想段階の Baikal を紹介する静的サイト。ビルド工程や実行時のライブラリ依存はなく、HTTP サーバーでそのまま表示できる。Google Fonts の取得に失敗しても本文と操作は利用できる。

## プレビューと検証

リポジトリのルートで実行する。

```sh
python3 -m http.server --bind 127.0.0.1 --directory design 8000
# http://127.0.0.1:8000/index.html
# http://127.0.0.1:8000/program.html
```

別のターミナルで静的な契約を確認する。

```sh
python3 -m unittest discover -s tests
node --check design/landing.js
node --test tests/landing-motion.test.mjs
```

テストは英語 UI、元の8件のプログラム名・検証方式・指標・説明・図・詳細リンク、ランドマーク、ローカルファイルの存在、研究詳細からのアンカー、CSS の分離、構想段階の明記を検査する。Node.js のテストはブラウザの通知と Canvas を模擬し、自動回転、動きを減らす設定の反映、フレーム間隔によらない速度、一周分の描画範囲、非表示時の停止を検査する。画面の読みやすさや実ブラウザでの操作の完了を保証するものではない。下記のブラウザ確認も行う。

## ファイルと変更範囲

| ファイル | 役割 |
| --- | --- |
| `index.html` | 英語の紹介ページ。元の8件の研究プログラム、検証のしくみ、参加への入口 |
| `landing.css` | トップ専用のトークン、レイアウト、状態、レスポンシブ仕様 |
| `landing.js` | 点群の自動回転、端末設定・表示状態による描画制御、目次の開閉補助 |
| `program.html` | 既存の研究詳細サンプル。今回の刷新対象外 |
| `tokens.css` / `style.css` | 既存の研究詳細用。トップは読み込まない |
| `assets/` | 既存の Nyx Foundation ロゴ、既存の Baikal マークを再利用した favicon |

**見た目の刷新では、既存の UI 言語・プログラム情報・図・詳細導線を削除・翻訳・別の内容に置換しない。内容を変える場合は、見た目の変更とは別に承認を得る。** 元の8件の基準は `tests/fixtures/original_programs.json` に保持する。

トップページの視覚仕様は本書に記す。製品の意味と検証原則はルートの [README](../README.md) に従う。ルートの `DESIGN.md` が記す旧テンプレートの配色・書体と、刷新したトップの仕様は別である。研究詳細は従来の The Dive 表現を維持する。

## トップの視覚設計

[Plastic Human](https://plastichuman.org/) の白と鮮烈な青、大きな文字、点群、番号付きの章から着想を得た。人体モデル、画像、音声、実装コードは使用していない。

研究の進展に関心を持つ読者に向けた、研究特集のような紹介ページ。ENERGY / RHYTHM / MOTION は **3 / 3 / 2**。詳細ページの作業的な読み方とは分ける。

| 判断 | 仕様と理由 |
| --- | --- |
| 配色 | `#fafaf8` の紙面と `#1531f5` の青。参考サイトの研究展示らしい鮮明さを取り入れ、本文は `#172443`、補足は `#555e73` で読む密度を下げる |
| 固定ライトテーマ | 白地と青い点群のコントラストを保つため。青い検証章はページ内の反転であり、OS のダークテーマではない |
| 欧文 | Schibsted Grotesk。幅のある低重心の字形で、冒頭と末尾に誌面の見出しとしての強さを持たせる |
| 注釈 | IBM Plex Mono。章番号、検証方式、指標、参照先を本文から区別する。本文全体や大見出しには使わない |
| 構図 | 冒頭は大見出しと立体図。研究は元の8件を省略せず、48rem 以上で2列、未満で1列に常時表示。検証章は反転した手順図、参加はリンクの一覧 |
| 余白 | 左右は `clamp(1.25rem, 4vw, 4.5rem)`。章の上下は小画面 4rem、中画面 5rem、大画面 7rem。研究の説明はこれより密に組む |
| 点群 | 結び目状の点群を使った装飾モーション。研究データや検証状態を表さない。図番号・ラベル・指示線を付けず、読み上げの対象から外す |
| 図解 | 元の8件の SVG を保持。各課題の名前・方式・サンプル指標・説明・期待する用途・詳細リンクと並べる。図の補助文字は青、線はコントラストを上げ、検証・反証の緑と赤は維持する |
| 矢印と開閉記号 | 矢印はページ内の上下移動と別ページへの遷移、プラス・マイナスは開閉の状態を示す |
| 動き | ユーザーの指定により、点群はスクロール操作なしで約90秒に一周する。形を保ったまま立体構造を別の角度から見せる。音声、スクロールの乗っ取り、本文を隠す出現アニメーションは使わない |

### 表示と操作

- 40rem 未満では冒頭を一列に組み、本文、大見出し、図の順に読む。ヘッダーは固定せず、文字拡大で折り返しても本文を覆わない。40rem 以上では図と文章を並べ、ヘッダーを追従させる。68rem 以上で広い誌面にする。
- 点群は Canvas 2D。解像度倍率は 2 まで。`requestAnimationFrame` の経過時間で回転角を進め、フレームレートによって速度を変えない。回転の三角関数はフレームごとに一度だけ計算し、各点で繰り返さない。一周を通じて散らばった点も描画範囲内に収める。
- 画面外・別タブでは予約済みフレームを取り消す。復帰時は停止していた角度から再開し、非表示だった時間を回転に加算しない。動きを減らす設定で静止中にサイズが変わった場合は、表示中なら静止図を描き直すが、自動回転は再開しない。
- ユーザーの指定により、ページ内の停止ボタンは置かない。`prefers-reduced-motion: reduce` では静止する。端末設定を実行中に変えた場合も反映し、動きを減らす設定を解除すると回転を再開する。
- JavaScript 無効時や Canvas のコンテキスト取得不可時は、HTML 内の静止図を表示する。本文、8件すべてのプログラム情報、詳細リンク、ネイティブの `details` による目次は利用できる。
- 目次は Escape で閉じ、フォーカスを開閉ボタンへ戻す。リンク選択時は対象章へフォーカスを移す。JavaScript 無効時は目次の開閉ボタンで閉じる。
- 研究詳細から参照される `#programs`、`#loop`、`#roles`、`#frontier` を、それぞれ対応する内容の識別子として保持する。
- データ取得、認証、提出フォームは設けていない。指標と Active / Audit は元のテンプレートの例示であり、稼働状態や実績として扱わない。各項目に Illustrative と明記し、架空の更新履歴や CLI のインストールコマンドは表示しない。

## 内容の境界

- 8件の研究プログラムは元のテンプレートから保持した想定例であり、稼働中のプログラムではない。一覧の直前にスコア・図・状態が例示であること、最新記録ではないことを記す。フッターにも Beta / concept stage と表示する。
- 元の「If solved」の説明は期待する用途であり、実証済みの効果や保証ではない。その区別と独立した検証の必要性を一覧の末尾に記す。特に折り畳みエネルギーは mRNA の半減期を、配列の列挙は臨床上の安全性を実証しない。社会目標の達成率や達成年は作らない。
- 検証済みの改善だけが、各 Research Program の単一の公式 Frontier を更新する。失敗・反証・再現失敗は共有知として残す。
- 開始後の検証契約は不変。欠陥があれば凍結し、後継プログラムに移る。過去の成果は削除しない。
- AI は来歴であり、責任主体は人間・組織。形式証明、シミュレーション、現実世界での実証を混同しない。
- 参加導線は公開 GitHub リポジトリの README、Issues、コミット履歴。未ログインでも閲覧できることを確認する。Issue の投稿など GitHub 上の操作にはログインが必要だが、閲覧に個別のアクセス権は不要。元の8件の詳細リンクはすべて共通の `program.html` に向かう。その既存仕様を維持し、一覧の直前に共通のサンプルページであることを表示する。

## ブラウザでの確認

- 320 / 390 / 720 / 1080 / 1440px、および文字拡大 200% で、横スクロール・文字の欠け・重なりがないか確認する。
- 目次の開閉・Escape・章への移動、8件すべての本文と図の常時表示・詳細リンク、本文スキップと先頭への移動をクリックとキーボードで確認する。
- 点群まわりに図番号・ラベル・指示線・停止ボタンがないこと、スクロールしない状態での自動回転、画面外・別タブでの描画停止と復帰、動きを減らす設定中のリサイズ、設定の切り替えを確認する。
- 通常、動きの低減、JavaScript 無効、フォント取得失敗の各条件で本文と操作を確認する。
- ページ内アンカー、詳細サンプル、外部リンクの行き先を一つずつ確認する。コンソールエラーとアクセシビリティ検査も確認する。
- 青と紙面、本文と紙面、補足と紙面、図の背景、白文字と青、操作の hover / active / focus の組み合わせを測定する。
